# YourDost Selenium Hybrid Automation Framework

## Overview

This project is a Selenium Hybrid Automation Framework developed to automate the core functionalities of the YourDost web application.

The framework follows the Page Object Model (POM) design pattern and is built using Java, Selenium WebDriver, TestNG, Maven, Log4j2, and Extent Reports. It supports cross-browser execution, screenshot capture, reporting, and is designed for CI/CD integration using GitHub Actions.
